USB 设备转发

Moonlight V+ · 原型稿 v0.1 · 2026-09-04
基于 usbipd-win 外挂方案。绑定（持久、需提权、本机停用）与转发（会话级、免提权、overlay 点选）两层分离。组件均对应现有实现：SettingsCard / ToggleRow / OverlayMenuPanel / OverlayToast。

设置页 · USB 设备转发卡片

挂在生态扩展页。总开关默认关闭；关闭时运行时不拉起 agent、不显示 overlay 菜单。
